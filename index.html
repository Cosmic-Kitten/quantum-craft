Frequently Asked Questions

Information regarding this open-source software project.

Is Quantum Craft a commercial product? +
No. Quantum Craft is a non-commercial, open-source software project created by Quantum Studios for community tools, client applications like Orbit Launcher, and web development demonstrations.

No. This software repository is an independent open-source web project created exclusively by Quantum Studios. We are not affiliated with quantumcraft.fun or CurseForge modpacks.
